# Godot Project

This directory is the complete Godot project root. Open this directory in the editor; `project.godot`, scenes, data, scripts, and tests all live below it.

Tests live under `tests/`: `strict_port/` replays the deterministic cases recorded from the original code, `runtime/` holds the runtime's tests and its end-to-end sessions. The commands are in the repository README's [Validation](../README.md#validation) section; what each check proves is in [the strict port contract](../docs/port/STRICT_PORT_FOUNDATION.md#verification).
